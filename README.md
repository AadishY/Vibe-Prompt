## 📂 Repository Structure

Every curated site prompt is organized in its own dedicated folder containing its complete documentation and assets:

```text
├── README.md                                  # Main repository index & directory
├── tools and source.md                        # Curated tools, video/photo libraries & prompt hubs
├── agent.md                                   # AI agent paired-programming instructions
└── [site-type-folder]/                        # Category / Site name
    ├── README.md                              # Complete prompt guide, art prompt, and code prompt
    ├── preview.png                            # UI preview screenshot
    └── assets/                                # (Optional) Generated visual assets & previews
```

## 🚀 How to Use These Prompts

1. **Browse & Pick a Concept:** Choose a site idea from the [Prompt Gallery](#-prompt-gallery--index).
2. **Generate Your Background & Brand Assets:**
   - Open the site's `README.md`.
   - Copy the **Artwork Generation Prompt** into Midjourney, ChatGPT, or your preferred image generator.
   - Adjust the customizable bracket values (e.g., `[SETTING]`, `[ERA]`, `[PALETTE]`).
3. **Build the Web Application:**
   - Copy the **Code Generation Prompt** into your AI coding assistant (Cursor, Claude, Antigravity, ChatGPT, v0).
   - Drop your generated assets in `public/` and watch your vibe-coded application come to life!

## ➕ Contributing New Prompts

Have a cool vibe-coded site prompt? Add it by creating a new folder:
1. Create a new folder named `your-site-type-name/`.
2. Add a `README.md` with:
   - Live demo links and reference sources.
   - Preview screenshots (`preview.png`).
   - The Artwork generation prompt (if applicable).
   - The Code generation prompt (Next.js / Vite / React / Tailwind).
   - Gotchas & architecture tips.
3. Update this root `README.md` table with your new site entry!
